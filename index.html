If Engine Uploader

If Engine Uploader is a small publishing application for the YouTube channel The If Engine, a science channel that explores "what if" scenarios with real physics.

What the app does

  • Uploads finished videos to The If Engine YouTube channel, owned by the app's developer.
  • Sets each video's title, description, tags, thumbnail, captions (subtitles) and playlist.
  • Schedules when each video is published.
  • Reads the channel's own YouTube Analytics (views, watch time, retention) to plan future videos.

Who can use it

The app is used only by the owner of The If Engine channel to manage that one channel. It does not offer accounts or services to the public and does not access any other user's data.

Google data

The app uses YouTube API Services with these permissions: upload videos (youtube.upload), manage captions, thumbnails and playlists (youtube.force-ssl), and read channel analytics (yt-analytics.readonly). Read the Privacy Policy for full details on how this data is handled.
