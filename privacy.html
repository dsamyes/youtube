If Engine Uploader – Privacy Policy

Last updated: November 2026

If Engine Uploader is a private, internal tool used only by the owner of the YouTube channel The If Engine to upload videos, captions and thumbnails to that channel and to read that channel's analytics.

Data we access

Through the YouTube API Services, the tool accesses only the owner's own YouTube channel: uploading videos, managing captions, thumbnails and playlists, and reading channel analytics.

How data is used and stored

Data is used solely to publish and improve the owner's own videos. OAuth tokens are stored encrypted as private secrets and are never shared, sold or transferred to third parties. No data from other users is collected.

Third parties

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
