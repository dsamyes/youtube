Privacy Policy – If Engine Uploader

Effective date: November 10, 2026

This Privacy Policy explains how If Engine Uploader ("the app") accesses, uses, stores and shares Google user data. The app is a publishing tool for the YouTube channel The If Engine. Home page: If Engine Uploader.

1. Data the app accesses

When the channel owner signs in with Google and grants permission, the app accesses the following through YouTube API Services:

  • YouTube channel data (scope youtube.upload): permission to upload videos to the authorized channel.
  • YouTube channel management (scope youtube.force-ssl): video metadata (titles, descriptions, tags), captions, thumbnails and playlists of the authorized channel.
  • YouTube Analytics (scope yt-analytics.readonly): aggregated statistics for the authorized channel, such as views, watch time, audience retention and traffic sources.
  • OAuth tokens: an access token and refresh token issued by Google, used to call these APIs.

The app does not access Gmail, Google Drive, contacts, or any data outside YouTube. It does not collect names, email addresses or data of viewers or of any other users.

2. How the data is used

  • To upload videos produced for The If Engine channel and set their metadata, captions, thumbnails, playlists and publish times.
  • To read the channel's own analytics so the channel owner can decide which videos to make next.

Google user data is not used for advertising, is not sold, and is not used to train generalized AI or machine-learning models.

3. Storage and security

OAuth tokens are stored as encrypted secrets in a private repository (GitHub Actions encrypted secrets) that only the channel owner can access. They are transmitted only over HTTPS to Google's APIs. Analytics data is kept only as aggregated summary reports for the channel owner.

4. Sharing

Google user data is not shared with, transferred to, or sold to any third party, except as required by law.

5. Retention and deletion

Tokens are kept only while the app is in use. Aggregated analytics summaries are kept for up to 12 months and then deleted. The channel owner can revoke the app's access at any time at myaccount.google.com/permissions; after revocation the stored tokens no longer work and are deleted.

6. Limited Use disclosure

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. YouTube API Services

The app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

8. Changes and contact

Changes to this policy will be posted on this page with a new effective date. Questions: github.com/dsamyes/youtube/issues.
